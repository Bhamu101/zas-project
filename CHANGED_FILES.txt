  notifications), ESP32_NODES, SENSORS, MAINTENANCE_ACTIONS, FIRMWARE_VERSION,
  BACKEND_VERSION, _STARTED_AT. Helpers: _deep_merge, _load_settings /

  online/nodes/sensors/pump/solar/battery/tank from the existing mock + kpis),
  _settings_payload.

  * GET  /api/settings                -> { settings, status, devices, meta }
  * PUT  /api/settings                -> SettingsUpdate (partial ok) -> deep-merge
    onto current, _validate_settings (422 on rule violation), persist, return
    the GET shape.
  * POST /api/settings/maintenance    -> { action } from MAINTENANCE_ACTIONS;
    "factory-reset" restores DEFAULT_SETTINGS + persists; all log to BED_ACTIVITY.
- backend/.gitignore: + system_settings.json.
- No existing endpoint or the /api/dashboard payload was changed.

Frontend (irrigation-dashboard/src):
- NEW lib/currentUser.js — CURRENT_USER + isAdmin/canEditSettings. Centralises
  the role the TopBar already shows ("Administrator"); no login added. Non-admin
  => whole page renders read-only (controls disabled, no SaveBar, notice shown).
- NEW lib/settingsApi.js — fetchSettings / saveSettings(patch) / runMaintenance.
- NEW hooks/useSystemSettings.js — loads the payload once; exposes
  { settings, status, devices, meta, loading, error, saving, save, reload }.
- NEW components/settings/controls.jsx — opaque-card UI kit (deliberately NOT the
  translucent .bg-surface glass): SettingsCard, Field (label + InfoTip tooltip +
  hint/inline-error), Toggle, ToggleRow, NumberField (unit suffix), RangeField
  (slider + synced number), SelectField, StatusChip (green/amber/red/gray/blue
  tones), ConfirmDialog (Esc to close), Toast (auto-dismiss), SaveBar (sticky,
  Cancel / Save Changes, "unsaved changes" indicator). lucide-react icons only.
- REWROTE pages/SystemSettings.jsx (was a 29-line read-only list). Sections:
  System Status, Irrigation Settings, Water & Pump, Energy Management (with live
  Solar/Battery/Grid strip), Devices & Sensors (per-node + per-sensor rows from
  the backend), Alerts & Notifications (9 event toggles + 4 channels), System
  Information, Maintenance & Advanced (+ red Danger Zone with confirm dialogs).
  Edit model: sparse `edits` patch state -> `draft = deepMerge(settings, edits)`;
  `dirty` by deep compare; client `validate()` mirrors the backend rules and
  drives inline errors + blocks save; PUT sends only the patch; success/fail
  toasts; loading + error states. No state-syncing effect (patch cleared in the
  async handler after save/reset). Responsive: mx-auto max-w-6xl, cards collapse

- App.jsx — settings route now `<SystemSettings dashboard={data} />` (live

## 2026-09-08 — Real authentication (Supabase Auth) + backend hardening

Supabase project created: agri-intelligence (ref ewseaaucyujohlepufpo, eu-west-1,
free tier, org "Josi's Org"). URL https://ewseaaucyujohlepufpo.supabase.co

BACKEND
- backend/auth.py — NEW. Verifies the caller's `Authorization: Bearer <jwt>`
  against the Supabase project's PUBLIC JWKS (ES256/RS256). The backend never
  sees a password and holds no token-minting secret. Enforces issuer +
  audience="authenticated", so the project's own anon key can't be passed off as
  a user session. SUPABASE_URL is read lazily (NOT at import time) because
  main.py imports this module before it calls load_dotenv().
  PyJWKClientError -> 401 (token not signed by this project), genuine JWKS
  network failure -> 503.
- backend/main.py
  * All 10 /api/* routes now carry dependencies=[Depends(require_user)].
    Only "/" and the docs remain public.
  * CORS: allow_origins=["*"] replaced with an explicit localhost list +

    Methods/headers narrowed.
  * MAX_IRRIGATION_MINUTES=120 — StartIrrigationRequest.durationMin is now
    Field(ge=1, le=120) and re-clamped in the handler. Previously unbounded and
    forwarded to the ESP32 as sec=duration*60 (runaway-pump risk).
  * Crop-health: MAX_IMAGE_BYTES=8MB (base64 length cap + decoded-size check)
    and an ALLOWED_IMAGE_MIME_TYPES allowlist. cropName max_length=100.
  * ChatRequest: messages bounded to 1..40, content 1..4000 chars, role
    pattern-restricted — stops unbounded Gemini spend on the server key.
- backend/requirements.txt — added pyjwt[crypto].
- backend/.env.example + backend/.env — added SUPABASE_URL, CORS_EXTRA_ORIGINS.
